# 离线编辑器 UI 与弹窗开发

本 skill 定义本项目公共 UI 的视觉与交互约定。用户的新要求优先；只修改本次需求涉及的 UI，不因遵循本 skill 批量改写页面或扩大业务范围。

路径均相对当前仓库根目录。先读根 `AGENTS.md`，再读本次涉及的实现与调用方；产品规则改变时同步修改本文及相关参考，避免累计冲突规则。

## 按本项目结构划分职责

- 根包 `lib/` 是可复用离线编辑器；公共展示在 `lib/src/ui/modal/`，选区、命令、草稿应用及编辑会话在 `lib/src/editor/`。沿用已有 `Collab*` 名称，不为样式迁移批量改名。
- `example/` 是独立宿主包，通过 `path: ..` 使用根包；今日导向留在 `example/lib/daily_guidance/`。页面导航、封面、纸张背景、栏目、预览分享/点赞及宿主服务归 example，不能为统一弹窗把它们移入根库或另拆包。
- 根包跨目录使用精确 `package:cses_editor/src/...` import；example 内部跨目录使用 `package:cses_offline_example/...`。example 使用根库只能经 `package:cses_editor/cses_editor.dart` 等实际存在的公开入口，不能导入根包 `src/`。
- 先核对公开入口：当前 `lib/cses_editor.dart` 没有导出公共弹窗 Widget。宿主 UI 可在宿主内按同一视觉/布局规则组合；有实际跨包复用需求时，再设计最小公开契约并验证消费者，不为直接借用内部 Widget 扩大导出。
- 普通页面遵循现有信息层级、间距、Lucide 图标及交互一致性；今日导向保留既有纸张、封面和栏目风格。弹窗紫色主题只应用到弹窗子树，不把整页强制套进弹窗外壳或替换所有背景颜色。

禁止引入原协同包、Common SDK、Rust/FRB/Yrs、协同数据库、外部工作区路径依赖或本地 AppFlowy 副本；依赖约束以根 `AGENTS.md` 和 `pubspec.yaml` 为准。现有锁相关模型只按实例注入能力使用，不因旧名称恢复协同运行时。纯本地 `EditorCommandContext.localOnly` 模式不额外展示账号、锁或分享能力。

## 先定位职责，再选公共入口

先读 [展示函数](../../../lib/src/ui/modal/collab_modal.dart) 和涉及组件的独立文件，再检索已有消费者。核对取消/确认返回值、保存时机、只读/能力配置、焦点和控制器所有权；统一展示不移动业务事务。

| 形式 | 根包展示函数 | 内容外壳 | 场景 |
|---|---|---|---|
| 底部弹窗 | `showCollabBottomSheet<T>` | `CollabBottomSheet` | 媒体来源、图标、日期/天气设置、绘图源码、块操作 |
| 居中弹窗 | `showCollabDialog<T>` | `CollabDialog` | 图片/资源属性、文字链接、导入或离开确认 |
| 锚点菜单 | `showCollabPopover<T>` | 函数自动创建 `CollabPopover` | 编号、代码语言、表格行列、绘图视图/类型/模板 |

复用 `CollabModalHeader`、`CollabModalActions`、`CollabModalField`、`CollabModalSegments<T>`；组件不足时优先增加保留旧默认值的可选参数，不另造定位和主题系统。

菜单行用 `CollabMenuRow`、开关行用 `CollabSwitchRow`；禁止使用或包装 ListTile 系列及其 SDK 主题配置，包含测试夹具和 example。开关仅本体触发，标题/说明/图标/空白无行级切换事件。密度由 `CollabModalTheme.compactList` 传递，常规/紧凑最小行高51/42逻辑像素，大字可换行增长，保留禁用、键盘与无障碍语义。

每个公共 Widget 独立文件，私有 State/Painter 随所属组件；`collab_modal.dart` 只保留三类展示函数和私有定位，不聚合导出组件。精确导入所用组件。卡片、选择器、缓存图片及共用预览仍在 `ui/modal/`，只借用模型和回调，不反向导入 `editor/`。

## 展示与操作规则

- 弹窗配色从 `CollabModalColors.of(context)` 读取，支持亮/暗主题；圆角、按钮、输入、密度复用现有实现，不把设计数值散落到业务调用方。基线与场景位置见 [场景参考](references/modal-decisions.md)。
- 主要确认放右侧 `actions`；需要左侧删除/移除时用 `leadingAction`。图标/高亮表情的移除与右侧完成同栏；窄屏大字允许换行。菜单中的删除仍用整行 `CollabMenuRow`，不一律移到底部。
- 可用删除/移除的图标和文字同用 `danger`，禁用态沿用主题。只移除提及/卡片内容，不删除宿主实体。
- 标题栏说明由 `CollabModalHeader.subtitle` 单行省略、禁止软换行；原始链接完整传递，复制/打开/保存不能使用截短值。主标题可换行。
- 链接/卡片/嵌入视图项存在时，与上方资源操作加浅分割线。编号和绘图视图/类型/模板锚点宽220，其他默认265；选项显示当前勾选，插入/模板动作不虚构持久选中状态。
- 核心图标用已安装的 `lucide_icons_flutter`：下方插入 `listEnd`、删除 `trash2`、外部打开 `externalLink`、复制 `copy`；行内公式 `omega`，独立公式 `sigma`。Figma/掘金使用现有通用图标，不额外引入品牌 Logo。
- 块操作头部按类型使用名称与图标，未知类型回退“内容＋file”；任务/会议快捷操作沿用各自专用头部。卡片只保留自身已有更多入口，不为普通正文、选中或锁装饰增添更多按钮。
- 日期/天气设置使用固定居中预览、左右循环箭头及下方名称（当前分别12/7种样式），预览置于 header，设置区独立滚动，取消/应用固定底部。短视口压缩预览；取消/下滑不写入，应用一次事务，无修改不新增历史，切回原样式恢复原尺寸。
- 字号、字距、行距沿用工具栏横向子菜单，返回/默认固定，仅数字滚动；即时生效、回显并保留键盘/菜单，不叠加底部路由。默认只清对应局部覆盖，不误清其他样式，混合值不误标默认。
- 独立公式整卡进入统一面板；新建只含源码/预览/取消/创建，编辑的块动作位于预览下，删除左下、取消/保存右下。分割线整条进入样式面板，新建先暂存，完成一次插入；编辑沿用原即时应用契约。分页符整条标记触发块操作，只读禁用点击，不加右侧更多按钮。
- 封面位置以图片内上下拖动配提示，不恢复滑条/百分比；保存才提交。表情完整目录、搜索、肤色、最近及固定 Tab 保留，由选择器管理有限视口，移除/完成归公共操作栏。
- 段落链接仅在宿主明确配置 `buildParagraphLink` 且节点有稳定身份时显示；草稿不凭空生成分享链接。保留专用资源/代码/会议号复制入口，公共“复制内容”仅沿用高亮块及绘图现有规则。

## 布局易复发问题

1. 展开面板的短正文必须填满剩余高度：`expand: true` 用 tight，默认 loose 按内容收缩；不靠固定高度或尾部占位掩盖按钮下空白。
2. 底部外壳已处理键盘、安全区及正文滚动，业务层不重复避让或嵌套无界滚动。带惰性目录用 `scrollBody: false, expand: true` 获得有限高度，自管滚动；保留固定搜索/Tab/操作栏。
3. 操作栏左侧自然宽度且不超过一半、右侧剩余空间贴右，不用两个等宽 Expanded 拉大空隙。
4. 锚点传按钮/序号自己的 `Builder` context，不传整行/整卡，沿用上翻及屏幕/键盘限幅。长菜单在正文增加滚动，公共标题/关闭入口固定。
5. 测试 MediaQuery 与逻辑画布一致，区分 padding/viewPadding/viewInsets；默认测试字体不代表真实中文排版，历史截图不充当本轮验收。

## 保留编辑与宿主契约

- 公共展示函数等待 `route.completed` 后才返回，不能仅等 pop 就执行依赖子组件释放的命令。调用方负责选区、输入会话及正文焦点恢复；复制、预览和媒体交互不擅自恢复键盘。
- 写入前后按现有命令核对页面 mounted、编辑器是否关闭、文档/节点身份、会话及快照。宿主切换文档/账号或异步加载替换节点后，旧结果失效；本地模式仍需这些保护，不引入远端服务来实现它们。
- 权限来自当前实例的只读/能力配置和显式宿主端口，未注入服务按既有契约隐藏或禁用，禁止进程级账号/服务兜底。已有锁能力时保留继承锁、解锁授权及旧草稿失效；锁定保留打开/复制，禁止写入动作。
- 取消丢弃草稿，确认沿用原事务/撤销；原本即时应用的入口不擅自改成延迟保存。上传/保存/分享有忙碌与异常边界，按钮迁出选择器时同步迁移防重入和错误提示。
- 创建者释放 Controller、订阅、定时器、客户端；展示层不释放借用资源。删除需保留末块补空段落、撤销及资源释放，不能只验红色入口。
- 今日导向 UI 保留宿主身份检查、编辑/预览模式、存储和正文协议；分享/点赞等能力由宿主提供，不迁入通用展示层。
