# 关闭栏目不弹键盘改动审查

日期：2026-11-03。范围仅为本轮关闭栏目的焦点与选区改动及相应回归。

## 结论

未发现需要新增修复的问题。

- 页面在关闭前同步关闭正文输入连接并释放焦点；没有在异步完成后重新获取焦点的代码。
- 关闭事务显式将 afterSelection 设为 null，共用命令清除旧 selectionExtraInfo；键盘服务收到空选区后关闭输入连接，不会把光标移到首段。
- 创建栏目仍沿用原来的 afterSelection 定位。关闭草稿、正文内容、撤销重做与再次点击输入能力保留。
