# 今日导向划词创建会议

## 接口契约

- 本地后端仓库 `cses-java@c6d6e880c0` 的 `MeetingManagerController.createMeeting` 将 `POST /meeting/create` 返回为 `MeetingDetailView`。`MeetingCommandHandler.createMeeting` 在创建事务提交后返回详情，`MeetingDetailView.normalizeData` 将持久化的 `entry.id` 写入 `meetingId`，会议号单独存于 `number`，主题为 `title`。
- SaaS 使用已有平铺响应解析器读取顶层回执。旧环境若只返回成功标记，发布页正常退场，导向提示缺少会议 ID 并保留选中文字。

## 交互与保存

- 移动端单段普通文字选区可通过宿主注入的发布与导航端口创建会议。发布页预填可编辑主题，退场后校验会话、权限、块身份和正文快照。替换沿用已有 `meeting` 行内引用协议，并作为一项正文撤销记录。
- 会议创建即时生效，引用随今日导向保存。编辑态包含详情入口，已保存的只读海报展示引用，重开编辑可打开详情。

## 验证范围

- 编辑器 6 个用例通过。覆盖发布成功后的详情入口与撤销、取消、原文变化、写入守卫拒绝、撤权后重新授权，以及已有任务提及交互。
- SaaS 19 个用例通过。覆盖创建接口顶层回执、缺少 ID、发布路由预填与退场、保存和重开后的会议引用，以及已有会议类型和读书会流程。
- 离线示例 33 个既有用例通过，覆盖原生提及、实例服务装配及日导向的保存和预览。
- 编辑器、SaaS 和离线示例的目标静态分析通过，两个改动仓库的 `git diff --check` 通过。
- 后端契约以本地源码核对，客户端以测试回执验证。未在部署环境发送真实创建请求，也未进行真机联调。
