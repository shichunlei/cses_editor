# SaaS 长图保存相册轻提示真机验收

2026 年 11 月 10 日，在荣耀 MTN-AN00（Android API 36，1200 × 2640）从成果导向列表打开同一条已有测试记录，经模板预览进入长图分享页，点击底栏「保存」。

| 场景 | 手机反馈 | 相册核对 |
| --- | --- | --- |
| 正常包保存成功 | 浮层显示「已保存到相册」，随后消失 | 新增 1 张长图，文件为 506,516 字节 |
| 临时失败包 | 浮层显示「保存失败，请重试」，随后消失 | 保存前后文件列表一致 |

临时失败包仅将相册插件入参改为不可解码的图片数据，由 Android 插件实际返回失败回执。生产页面的结果判断、轻提示和底栏布局均走正常路径。测试后恢复源文件并装回正常包。

两种场景的底栏上沿在提示前、提示中和提示后均位于物理像素 y=2181。提示消失后，底栏与提示前逐像素一致。
