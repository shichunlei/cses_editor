# 编辑保存后直接预览（2026-11-03）

编辑页显式保存成功后，使用同一控制器、正文与路由直接进入预览；关闭日期选择，隐藏保存、撤销、重做、编辑菜单，显示宿主用户栏与分享、点赞入口。控制器增加单向预览权限，只有当前修订保存完成且无在途请求时才能进入；所有事务、日期写入与 flush 均检查当前只读权限。

保存失败保留编辑和重试能力；修正沉浸式页面保存错误行被 AppBar 遮住的问题，将错误和重试按钮放在顶部安全区及操作栏下方。异步成功后仍检查页面、文档与宿主会话，过期保存不能进入预览。
