# 首页固定编辑/预览入口与只读权限

日期：2026-10-29（Asia/Shanghai）。

## 修改

- 首页提供“编辑”和“预览”两个入口，分别携带 `JournalPageMode.edit`、`JournalPageMode.preview` 打开同一服务记录。
- LocalJournalPage 在初始化时捕获模式，移除页内预览切换按钮、切换状态和第二份临时预览控制器。改变同一已挂载页面的 mode 会冻结旧会话，必须通过新路由重新选择模式。
- 编辑页保留保存、撤销/重做、原键盘菜单和业务动作；预览页只读，隐藏保存、撤销/重做、栏目关闭、日期修改和键盘编辑操作。
- LocalJournalController 新增不可变 readOnly 权限；只读模式关闭自动保存，拒绝正文事务、日期修改和 flush 写入，返回/切后台/销毁也不提交数据。即使视图错误设置 editable=true，控制器仍拒绝写入。
- 继续沿用 bodyContent 数据适配、orientType 标题和原记事本样式；导航模式不进入保存 JSON。
- 原预览布局/格式回归改为打开独立只读快照路由，不在产品编辑页恢复测试专用切换按钮。
- 设备集成测试源码改为保存后返回首页，再从预览入口读取；本轮未运行真机或重新安装手机应用。
