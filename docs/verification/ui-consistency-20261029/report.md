## 检查与发现

检查根包公共展示目录、弹窗调用与今日导向宿主入口，检索 ListTile 系列、SDK Icons、原生独立弹窗、硬编码错误色及跨包内部 import，并对照相关路由、主题、菜单/开关行及消费者。根包已有公共外壳、开关本体触发、菜单锚点等实现继续复用；本轮明确差异如下：

- 宿主两类选人弹窗和分享各自维护标题、外壳及键盘留白，未共用弹窗视觉；组织选人的搜索随目录滚动。

- 离开确认缺少与其他弹窗一致的局部主题与明确的主操作；放弃修改未使用危险色。
- 根包图片、资源编辑的错误文字使用固定红色，缺少亮暗主题配对。

## 调整

- 在 `example/lib/daily_guidance/ui/` 内提供宿主专用路由、局部主题、标题及底部外壳，不导出根包内部 UI，也不引入新依赖。
- 分享、离开确认、单选人员、多选人员/部门统一局部弹窗视觉；路由等待完整退场后返回，保留原结果与权限/会话/文档检查。确认主按钮突出、放弃修改使用当前弹窗危险色。
- 人员搜索与标题固定，目录在有限高度内独立滚动，确认固定底部。左侧已选数量按自然宽度且不超过一半，右侧按钮贴右；窄屏大字不强制等宽列。只在外壳处理键盘与安全区。
- 选人菜单行保留最小高度，撤权时禁用勾选/钻取控件；保留长名称换行、原组织查询与去重快照。
- 替换上述 SDK 图标为 Lucide，保留待办圆环/勾选和现有业务配色。
- 根包两处错误提示使用 `CollabModalColors.of(context).danger`。
- 更新 skill 场景参考，记录当前宿主组件和实际测试入口。

保留今日导向纸张色、封面、栏目、正文排版、页面分享/点赞布局及宿主服务边界；未改块协议、公开根包 API 或依赖。其他在途工作区修改保留。
