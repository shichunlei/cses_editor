# 导向预览和分享状态栏验收

2026 年 11 月 10 日使用荣耀 MTN-AN00（Android 16，API 36）验证。Android 宿主合并当前路由请求和原横屏策略，只控制顶部系统状态栏。

| 操作 | 真机结果 |
| --- | --- |
| 打开成果导向编辑，收起键盘进入预览 | 编辑显示状态栏，预览隐藏。 [预览](preview.png) |
| 点击分享 | 状态栏保持隐藏。分享长图中心线首个图像像素位于屏幕 y=0，底部渠道区固定。 [分享](share.png) |
| 关闭分享，再退出预览 | 返回预览仍隐藏，回到详情恢复。 [退出](exit.png) |
| 独立打开工作成果预览 | 进入和切回前台时隐藏，系统返回后恢复。 |

系统记录显示上述场景的底部系统导航栏均保持可见。最终 Android 调试包已构建并装到手机。36 项 Dart 回归测试及静态检查通过。iOS 的隐藏和恢复调用由组件测试验证。
