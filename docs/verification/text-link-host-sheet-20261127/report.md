# 划词文字链接宿主表单

`CollabHostServices.editTextLink` 提供可选的表单入口。编辑器提供共同旧地址、移除权限及字段校验，等宿主表单完整退场后复核原文、格式、块权限和编辑会话，再独立写入可撤销的 href。宿主只交付确认的地址或明确的移除结果；空白输入不能隐式删除链接。无宿主回调时继续用内置表单。

## 自动验证

- 编辑器 `editor_selection_link_test.dart` 从真实划词菜单覆盖默认表单、非法宿主回执、正文变化，以及只读撤销后重新可写时旧结果失效。
- 划词会议、任务和 iOS 选择菜单测试一并运行，共 31 项通过。
- SaaS `saas_guidance_editor_flow_test.dart` 通过真实成果导向划词菜单，验证 URL 键盘类型、模拟键盘避让、非法地址原地提示、取消、新增、预填编辑、移除、撤销和原有文字及加粗保留。
