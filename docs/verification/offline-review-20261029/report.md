# 独立项目复审与修复

日期：2026-10-29。范围：`cses_offline_editor`的实际依赖、构建配置、通用编辑能力及今日导向业务。
原项目只读，未提交、推送或改动其源码；[源文件核对](original-source-check.json)。

## 结论

未发现新项目当前源码依赖、解析后的依赖图或Android APK包含原协同包、Common SDK、FRB、Yrs或SQLite插件。
实际修复了图片持久缓存退化、宿主选人回调被覆盖、会话切换时异步状态可能恢复，以及检查工具/锁文件/接入示例的遗漏。
新项目仍只有通用编辑器包与底层fork；今日导向继续属于示例App业务层。

## 发现与修复

| 问题 | 影响 | 修复及依据 |
|---|---|---|
| P1：图片改为内存缓存后无法跨进程离线读取 | 已加载网络图片重启后断网可能无法展示 | 增加App私有目录文件缓存；完整URL用UTF-8哈希，位图/SVG共用单次下载，原子替换、30天刷新、断网回退；200文件/128MiB上限，不使用数据库。[7项缓存回归](image-cache-tests.txt) |
| P1：加载/预览的异步返回未统一复核宿主身份，退出保存失败会直接恢复编辑 | 旧页面可能在会话切换后展示迟到正文或恢复可写 | 宿主身份采样及操作返回检查，首次失效永久冻结并隐藏正文；旧会话只写原存储。存储/分区/服务等端口替换时禁止复用旧状态，销毁取消采样定时器。8项宿主边界回归已纳入业务全量 |
| P2：宿主提供的选人回调被内置面板覆盖 | 接入App自定义选人无法生效 | 优先调用宿主选人回调，内置面板作为缺省；二者统一借用受保护的权限信号。新增领航员/都来帮真实工具栏调用回归 |
| P2：检查脚本未覆盖底层fork、条件import、间接本地路径与原生配置 | “检查通过”不能充分证明独立性 | 扫描全部包/示例Dart、声明与override路径、锁文件、实际解析路径、原生配置及APK；正确解析file URI/转义路径并拒绝外部源码链接。[8项边界检查回归](dependency-guard-tests.txt) |
| P2：三份pubspec.lock受本机全局忽略规则影响 | 新目录或换机器时无法复用本次解析结果 | 仓库规则明确保留三个包/宿主锁文件；干净副本使用本机第三方缓存离线解析三个项目并通过消费者测试 |
| P3：接入注释仍引用旧Demo入口和不存在的协同Controller | 复制示例无法接入，容易误以为仍需原项目 | 改为新宿主入口及LocalEditorController；同步说明实例服务、身份失效、图片缓存和生成目录维护 |

没有通过删除旧失败证据、跳过测试、改生成Dart数据或清理原项目来获得通过。
测试新增时曾缺少ValueListenable导入，已修复；[初次编译记录](host-boundary-tests-initial.txt)。
