日期 2026-11-05

- 两套模板使用 SaaS 海报外壳的原版默认图片和各自满宽品牌图。问候按原版时段选取，日期由当前记录提供，头像和姓名由宿主提供。
- 汇丰永盛 V2 恢复相框上方的问候及日期，框内右上日期牌与左下头像和姓名。成塔服饰 V2 恢复顶部问候与星期、圆弧英文问候、独立日期牌、跨在照片与正文卡交界的头像以及暖白圆底正文卡。
- 保留离线块编辑和顶部悬浮按钮。只读预览和分享使用原版栏目标题标记和正文间距，正文由同一份文档渲染。编辑横格、可写块及动态栏目遵循宿主编辑器规则。
- 企业图库、真实账号和 SaaS 海报的自适应主图高度没有接入。本轮比较的是默认离线素材与原版构图，未进行逐像素比较。

静态分析和 14 项分享、页面模式、键盘光标测试通过。Android MTN AN00 分别打开两套模板，输入长文并点顶部保存，检查分享 PNG 从封面到完整正文末尾和满宽 Logo。测试结束恢复原草稿。 `git diff --check` 通过。
