# 日导向划词创建任务

验证日期为 2026-11-18。

## 功能边界

- 手机日导向在单段普通文字的划词菜单中提供「创建任务」。每次打开按本次选中文字预填任务标题，空间、工作项、负责人和截止时间重新初始化。标题、空间和工作项必填，负责人和截止时间选填。
- SaaS 借用任务模块的用例和会话。切换空间时清空工作项和负责人，切换工作项时清空负责人。提交期间拒绝重入，缺少确认回执时保留原文。
- 返回正式任务 ID 后，以单次撤销命令替换选区。确认回执迟到且选区失效时，保留正文并提示。正文显式保存沿用 v9；编辑和只读预览均可打开任务详情，预览只提供详情操作。
- 沿用行内 `mention`、`mentionId` 和 `mentionType: task`，无新增块或持久化字段。桌面包版本及适配范围见 [块兼容记录](../../block-adaptation.md)。

## 划词标题预填回归

任务创建端口传递本次选区文字，宿主将标题交给本次路由的输入控制器。取消后重新划选不同文字，以新选区初始化标题；前一次修改的标题和空间选择随原表单释放。用户编辑标题后，创建命令提交本次修改值，引用继续采用服务端确认的回执。

本次编辑器任务及会议 8 项测试、SaaS 划词 3 项流程测试通过。覆盖编辑器传递选区标题、取消后重新选择、编辑预填标题及创建保存重开后的详情入口。编辑器、离线示例及 SaaS 目标静态分析通过，两个仓库的 `git diff --check` 通过。本轮沿用现有行内引用协议。


## 创建页复用现有表单组件

创建任务页复用 `SingleInputView`、`SingleSelectView`、`CustomAppBarView`、`CustomSingleChildScrollView`、`BottomNavigationBarBg` 和 `RadiusInkWellWidget`。空间、工作项和负责人使用已有的 `BottomSingleSelectDialog`，确认后回填本次选择；截止时间使用统一日期时间弹窗。标题控制器、输入焦点和表单滚动控制器由本次路由创建并释放。

SaaS 目标静态分析及 3 项划词流程测试通过。任务用例检查实际复用组件、标题预填、空标题拒绝、取消重开、候选迟到、防重复提交、引用保存和详情打开，并覆盖 360×760 视口配 280 键盘避让以及日期选择取消。两个仓库的 `git diff --check` 通过。本轮未进行真机验证。


## 任务页面三件套

SaaS 的 `presentation/create/` 和 `presentation/detail/` 各使用 `page.dart`、`logic.dart`、`binding.dart`。Page 展示现有组件并处理路由与弹窗，Logic 编排本次表单、查询和提交，Binding 将宿主仓库装配为用例依赖。`routes/navigator.dart` 沿用模块公开的创建和详情导航函数，按路由标签隔离 Logic，等待退场后完成依赖释放。

目标静态分析及 5 项测试通过。两个 Binding 用例分别覆盖创建表单隔离、在途创建被关闭时的回执丢弃、控制器释放，以及详情关闭后的迟到响应拒收。三个日导向划词流程覆盖当前任务及既有会议、人员选择行为，任务流程保留标题预填、窄屏键盘、表单校验、创建回填、保存重开和详情入口。旧页面路径及类名检索已清理，两个仓库的 `git diff --check` 通过。


## 详情复用单对象控制器

`TaskDetailLogic` 继承 `BaseObjectController<TaskDetail?>`，通过 `loadData`、`initData` 和基类刷新流程发布 `bean/pageState`。详情页监听这两个状态展示加载、错误和内容。读取有效性同时核对来源会话、生命周期和当前请求代次。

本次目标静态分析及 7 项回归测试通过。详情覆盖关闭后拒收回执、重试只发布最新结果、业务错误进入基类错误态及成功重试恢复；同时运行创建 Binding 隔离与三个日导向划词流程。两个仓库的 `git diff --check` 通过。
