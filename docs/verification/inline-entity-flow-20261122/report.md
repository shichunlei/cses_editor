# 会议与任务行内引用样式和自然换行验收

2026-11-22。会议与任务引用共用无底色蓝字，分别保留会议与剪贴板图标。标题随正文自然换行、完整显示，普通及自然高度预览、静态截图沿用同一投影；不再以单行标签省略会议长标题。

## 实现边界

- 原任务专用排版器归一为 `lib/src/editor/collab_entity_text_flow.dart` 的 `CollabEntityTextFlow`；检测、样式、图标和原子命中采用会议/任务职责命名，旧文件、旧类及方法无生产残留，不保留转发文件。
- `CollabTextAlignmentBuilder` 对会议与任务统一使用现有文字外壳，按正文剩余宽度自然断行。名称只在渲染层展开，图标与标题开始保持相邻；字号、字重、删除线沿用正文，文字与图标共用按前景亮度选择的蓝色。
- 显示 UTF-16 偏移始终映射回单个正文字符；多个引用、普通文字及非 BMP 字符可混排。光标、跨行选区、详情、删除和撤销复用原映射和原子身份校验，不修改 Delta、BlockCraft JSON、ID、原属性或缓存协议。
- 块 State 拥有投影及点击识别器，重投影复用仍存在的识别器、释放移除项，dispose 统一释放。文档和宿主业务资源不归投影持有。
- 编辑态仍打开原操作面板，会议保留转卡片入口；显式预览直接派发宿主详情，人员能力不变。旧任务专用预览开关仍只开放任务，测量/截图与 disabled 规则不因共用排版而放宽。
