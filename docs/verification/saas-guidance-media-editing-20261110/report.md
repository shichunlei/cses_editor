## 交互边界

- 取消来源面板、编辑权限失效或原块变化时，不写入迟到的选件结果。现有 OSS 上传接口会完成已经开始的请求，取消只丢弃当前编辑器中的结果。
- 同名不同地址的附件按完整地址分开缓存，下载完成后才交给原生应用。
- 保存仍遵循原主栏目填写规则。仅媒体的可选栏目可随记录保存。
