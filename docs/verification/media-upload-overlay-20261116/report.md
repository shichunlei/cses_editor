# 媒体上传卡片进度遮罩

2026-11-16

共用媒体来源面板把上传进度画在本地文件卡片的前景。浅紫色半透明遮罩从左侧填充至实际进度，并沿用卡片圆角。图标、文件名、文件大小和重选提示保持原位，底部按钮在上传期间切换成禁用的「上传中」。

## 验证结果

- `dart format` 格式化面板和测试文件。
- `flutter analyze --no-pub lib/src/ui/modal/editor_media_source_panel.dart test/editor_media_upload_progress_test.dart` 通过。
- `flutter test --no-pub test/editor_media_upload_progress_test.dart test/editor_shortcut_toolbar_test.dart test/editor_service_isolation_test.dart --reporter expanded` 共 34 项通过。
- 新增测试从实际媒体来源路由打开图片、视频、音频及附件上传，在 320 逻辑像素宽度下检查 0%、42%、100% 的遮罩边界、卡片内容及按钮的位置、禁用状态和成功返回。视频用例覆盖暗色主题，附件用例覆盖失败后重试、取消和迟到结果。
- `git diff --check` 通过。

## Android 真机验证

2026-11-16，荣耀 MTN-AN00，Android 16，1200 × 2640 物理像素。通过离线示例编辑器的「添加」入口分别上传 PNG、WAV、MP4 和 TXT，测试服务将设备上的真实文件分段发送至手机本地 HTTP 接收端。四个文件均按字节核对一致，上传后对应媒体块插入测试正文。

- 对照选中文件、约 25% 和约 75% 三个状态。四种文件的浅紫遮罩都从卡片左边缘向右延伸，截图实测覆盖宽度分别为 24.77%–25.05% 和 74.95%–75.05%。界面只通过遮罩宽度展示进度。
- 逐次测量卡片、图标、文件名、大小及重选提示、底部按钮的屏幕位置。三个上传阶段均与选中文件时一致。
- 在约 25%、50%、75% 时尝试点击「上传中」。每类文件的上传调用次数均保持为 1。

[查看真机截图对照](android-upload-progress.png)。从上到下为图片、音频、视频和附件，从左到右为选中文件、约 25% 和约 75%。

该轮使用测试服务和本地 HTTP 接收端。Android 播放器拒绝了测试回环的明文 URL。

## SaaS 测试环境真实 OSS 验证

同一台荣耀 Android 16 真机安装包含进度遮罩的 SaaS 测试包，从测试环境成果导向记录的媒体卡片进入替换流程。通过原生选择器选取专用目录中的合成文件。每次上传的进度回调均达到测试文件的完整字节数，随后弹窗自动关闭并应用替换结果。以下比例为原生录屏的遮罩宽度实测值。

| 类型 | 已上传字节 | 从左向右填充 | 上传中点击次数 | 实际 OSS 上传次数 |
| --- | ---: | --- | ---: | ---: |
| PNG 图片 | 27,011,273 | 25.5% → 74.5% | 3 | 1 |
| WAV 音频 | 26,989,244 | 24.8% → 75.2% | 3 | 1 |
| MP4 视频 | 27,000,000 | 25.0% → 74.3% | 3 | 1 |
| TXT 附件 | 26,542,080 | 25.2% → 75.4% | 2 | 1 |

四种文件的卡片、图标、文件名、大小及重选提示在录屏中均未见移位。图标和文字边缘与选中文件时相比最多相差 1 个录像像素。界面以遮罩宽度表示进度，底部按钮显示「上传中」。各阶段通过设备实际点击按钮坐标，上传日志每类只有一次启动。[真实 OSS 上传录屏截图对照](saas-oss-progress.png)

PNG 上传后的正文卡片显示「图片加载失败」，该问题发生在替换弹窗退出后。测试结束时放弃本轮替换草稿，原记录正文保留，四个合成文件已登记到测试环境。
