## 已修复发现：另一类型历史正文与真实自定义栏目合并

原 Codec 已对 todo/expected-effect 内部键做避让，但 legacy-orient/legacy-result 仍固定映射为 custom:legacy-*。后端真实 dailyCustomField.key 若恰好同名，会投影到同一栏目，标题、关闭状态和嵌套内容归属混在一起。

在 ORIENT / RESULT 两类正文中加入同名及 -1 后缀自定义栏目、另一类型历史正文及其嵌套 daily-body，并分别验证可见和隐藏状态。修复前 4 项稳定失败，见 [失败证据](regression-before.log)。

修复 `lib/modules/mutualism/presentation/orient_result/editor/body_content_codec.dart`：全部历史区域共享源树占用键避让；真实自定义字段保留原 key 和标题，历史区域仅在冲突时使用最小可用数字后缀。嵌套区域继承实际分配后的历史键，不按字面 legacy 前缀推断。todo/expected-effect 的空占位折叠仍限于原两类字段，不扩展到另一类型历史正文。无碰撞时键保持不变，原正文、区域和块 ID 不变，不新增后端协议或视图映射。

新增 4 项回归验证栏目独立、隐藏恢复、分别修改、原树往返和主字段隔离；修复后全部通过。字段桥接注释中误称 recordId 为 rootId 的文字同步改为当前槽位业务 ID，执行协议没有变化。
