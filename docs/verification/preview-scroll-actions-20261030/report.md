# 预览滚动隐藏操作按钮（2026-10-30）

## 行为

- 预览正文开始拖动或惯性滚动时，分享与点赞按钮以 160ms 淡出；滚动结束后淡入。
- 隐藏期间禁用点击并排除按钮的无障碍语义；停止后恢复原操作，保留点赞状态。
- 仅监听当前正文视口的开始/结束通知，不使用延时定时器或持有滚动控制器，保留通知向祖先传递。
