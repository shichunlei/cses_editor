# 媒体用途切换与关闭任务等待验证

日期：2026-11-19。公开 API 增补在当前本地工作区，未暂存或提交。

`EditorResourceTracker` 观测媒体组件拥有的关闭 Future，通过 `trackDisposal`/`waitForDisposals` 支持截图准备和路由退出的真实等待。观测不取得播放器/文档所有权；父观测器先 dispose 时仍接受子媒体关闭登记。并发等待共享排空；失败保留原异常与堆栈，由等待宿主处理，无观测器时保持本地诊断。

音频作用域变化显式订阅继承状态；视频在换源、静态切换和卸载时交付同一关闭 Future。静态模式零播放器；可见只读媒体播放和进度保持原组件，未修改块协议或 JSON。
