# 会议任务图标解析回调验收

2026-11-22。会议、任务行内图标及编辑引用底部弹窗标题统一通过可选 CollabHostServices.mentionIconResolver 设置。宿主返回 IconData，库继续管理正文蓝色、尺寸、基线、自然换行及引用操作，不把图标写进正文。

## API 与所有权

- 回调签名为 `IconData? Function(CollabMentionType type)`，只为 meeting/task 同步调用。未配置或返回 null 使用原 Lucide 默认图标，人员及文档不调用该接口。回调必须是无副作用的纯映射，异常沿原构建或交互边界传播，不静默回退。
- 独立 WidgetSpan、CollabEntityTextFlow 换行投影及引用底部弹窗调用同一 collabEntityMentionIcon。投影在每次构建取得当前宿主映射，不缓存初始服务；原原子长度、UTF-16 映射、选区、点击、删除/撤销及资源释放逻辑保留。
- withMentionUserPicker 复制服务时保留解析器。宿主构造测量、预览、静态分享会话时须同源透传展示端口；测量/截图依然无导航权限。
- 业务选择自定义字体及其可用性，编辑器不依赖 SaaS、IconFont、账号或详情查询。该回调仅统一行内引用和其编辑面板，不改会议/任务卡片的其他图标或协议。
- 公共配置示例及空回退约定见 [集成文档](../../integration.md#会议与任务图标回调)，产品规则同步于界面 skill 和 README。

## 边缘案例与交付

建议持续覆盖宿主字体未加载/缺失、未知实体、回调抛错、不同主题映射、极窄多列、长标题跨行、来源销毁及默认/null 回退。回调不允许发起异步任务或改变正文；字体故障应由宿主原字体机制处理。

本轮未安装手机或验收真实字形；此前安卓截图不作为本次业务图标回调的真机证据。实现、测试和文档未暂存未提交，原示例依赖暂存内容保留。消费者继续用本地路径联调；Git 依赖发布需要先交付编辑器提交再同步 ref。
