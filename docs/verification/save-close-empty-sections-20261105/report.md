# 保存前关闭未填写的可选栏目

日期：2026-11-05。

## 行为

- 点击保存或确认“保存后离开”时，自动关闭只有空白文字的感悟、自检和自定义栏目。空格、换行、制表符和全角空格不算填写值；首栏今日导向/今日成果始终保留。
- 保留非空文字、提及、待办、人员业务行以及非文字块。多个空栏目在同一个事务中关闭，可整体撤销/重做。
- 沿用关闭草稿与现有隐藏栏目元数据，保存后预览、分享和重开不再显示空栏目，重新添加仍可恢复。完整提交参数中的空摘要继续按既有约定发送，清除后台旧值，不删除接口必需字段。
- 保存失败后仍可编辑，非空值保留，可撤销自动关闭并重试；异步返回继续校验页面和会话身份。
- 自动保存、输入过程和未确认保存的返回动作不会主动关闭栏目。没有修改正文协议或根包公开入口。
