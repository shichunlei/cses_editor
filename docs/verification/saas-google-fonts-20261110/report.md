# SaaS 公司模板直接使用 Google Fonts

2026-11-10。恒源生化等 11 套视觉的字体由模板直接通过 `GoogleFonts` 声明。库负责下载、注册和设备运行时缓存，项目不添加字体资产。分享最多等待字体两秒，之后按当时可用字形生成长图。图片解码、首帧及原组件动画仍独立确认。

恒源生化首次分享覆盖字体按时完成、字体请求一直未完成两种情况，并核对窄源 Logo 仍铺满长图。48 套模板的 144 项像素对照、6 项分享测试以及 11 套受影响模板的 22 项创建、保存、重开与长图流程测试均通过。变更文件通过 Dart 静态分析。旧内存加载方案的真机记录见[恒源生化首次分享](../saas-hysh-first-share-20261109/report.md)。

## Android 冷启动复测

荣耀 MTN-AN00（Android 16）。两轮均强制停止应用，只移开 Exo SemiBold 和 Righteous Regular 的缓存，再冷启动。使用测试账号从成果导向列表进入真实详情，打开「模板预览」并首次点击「分享」。验收包仅切换为恒源生化视觉与品牌，记录、账号和详情接口保持真实。慢速轮仅延迟两款 Google Fonts 请求 30 秒，图片和详情使用正常网络。
