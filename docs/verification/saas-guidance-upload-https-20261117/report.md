# SaaS 日填写图片上传 HTTPS 地址

2026-11-17。测试机的图片、视频、音频和附件域名模板仍使用 HTTP。SaaS 日填写上传完成登记后直接校验这些地址，导致图片停留在上传面板并提示「上传未返回有效的 HTTPS 媒体地址」。

SaaS 宿主在交付上传结果时把 HTTP 地址转为 HTTPS，保留对象路径和处理查询参数。视频封面使用同样的规则。缺少主机、带内嵌凭证或使用其他协议的无效地址仍不能作为上传结果。

## 验证

- 用带 HTTP 域名模板的合成 PNG 复现原错误。修复后确认地址转为 HTTPS，保留图片处理参数、文件信息和宽高比。另测视频与封面地址、非法媒体地址和迟到结果。
- 通过 HTTPS 读取曾用于真机上传验证的合成 PNG。原图与原文件的 SHA-256 一致，带移动端处理参数的地址也返回有效 PNG。
- SaaS 日填写页面测试覆盖成果导向和工作成果的媒体插入、替换、保存和重开。使用测试上传服务与保存仓库。
- 上传服务、日填写正文及编辑流程共 145 项测试通过。两份修改的 Dart 文件已格式化，静态分析通过，编辑器与 SaaS 两个工作区的 `git diff --check` 均通过。

## Android 真机复验

2026-11-17，荣耀 X70（MTN-AN00）、Android 16、SaaS PRE。构建并覆盖安装 2.3.6 Android Debug 测试包，沿用设备上的测试账号与当天「工作成果」记录。

1. 从正文「添加 → 图片 → 本地上传」进入系统文件选择器，在下载目录选中 `common-login-check-20261014.png`。设备文件为 33,105 字节，SHA-256 与原测试图片一致。
2. 点击「上传并插入」，弹窗自动关闭，PNG 随即显示在工作成果正文中。点击「保存」后进入只读预览，预览中也显示该图。
3. 退出预览后，从互生首页再次打开同一条「工作成果」。测试环境的详情接口返回 HTTP 200，重开后的正文完整显示图片。打开图片属性核对保存的是 HTTPS 地址。从该地址取回原图，得到 33,105 字节，SHA-256 与设备原文件一致。
