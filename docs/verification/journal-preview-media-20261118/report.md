# 今日导向预览媒体交互

日导向直接预览及保存后预览共用媒体交互。图片点击打开可缩放的大图，视频和音频使用原播放器的播放、暂停和进度条，附件卡片通过宿主或系统打开完整地址。预览继续隐藏块右上角的更多按钮，分享长图使用静态渲染。

## 自动化回归

- 根包目标静态分析无问题。图片布局、BlockCraft 快照渲染、编辑器输入、能力配置和实例隔离回归 24 项通过。
- `example` 目标静态分析无问题。媒体预览、页面模式、分享长图和预览排版回归 14 项通过。
- `example/test/daily_guidance/journal_preview_media_test.dart` 覆盖两种进入方式、全屏大图、音视频播放和暂停、水平拖动进度条、点击附件文件名、更多按钮显隐、正文 JSON、保存次数和退场释放。播放器平台使用测试实现，页面和播放器控件使用正式实现。

## Android 真机

在荣耀 MTN-AN00（Android 16）安装 Flutter 集成测试，使用手机本地服务提供 H.264 视频、AAC 音频及 HTML 附件。直接预览使用常规日导向纸张，保存后预览使用汇丰永盛 V2 模板。

- 两条路径均打开并关闭全屏大图。视频和音频均先播放并推进进度，再暂停并拖到约 7.3–7.6 秒，拖动后仍处于暂停状态。
- 直接预览点附件触发宿主打开回调。保存后预览点附件启动系统浏览器，本地服务收到附件页面请求。
- 两条路径均检查右上角更多入口隐藏，媒体操作期间正文 JSON 和保存次数保持一致。验收后移除了临时测试入口和 Android 回环网络配置。[真机结果](android.txt)
- 清理后重新构建并在手机上启动常规 `example` 应用。
