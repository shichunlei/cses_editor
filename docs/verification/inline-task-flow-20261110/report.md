# 任务引用自然换行

任务标题从当前行剩余空间开始，跨行时继续按正文排版，结束后接排后文。显示层映射展开后的文字偏移，正文继续保存一个 UTF-16 任务引用。标题任意一行复用相同操作菜单，删除及撤销作用于整条引用。

## 验证

- 编辑器全量 90 项测试通过，相关实现及回归用例的静态分析通过。回归验证起始行、后续行、接排后文、选区和光标、点击末行后的任务详情事件、整条删除及撤销。
- 在荣耀 MTN-AN00（Android 16）安装 Debug 包，打开同一条带任务引用的工作成果。在深色模板的待办段落中，标题首行紧接前文、完整续排到第二行，后文「我以后」接在标题末尾。[编辑截图](android-edit.png)
- 点击标题第二行能打开同一引用的菜单，删除后前后正文完整保留，撤销恢复整条引用。该真机记录的「打开任务详情」入口为禁用状态，详情回调由自动化用例验证。
- 预览和分享长图均保留相同的两行排版和完整标题。相册导出图为 739 × 5590 像素，核对使用实际导出图局部。[预览截图](android-preview.png) · [长图局部](android-share.png)
- 应用进程日志未见选区越界、提及点击失败、长图生成失败或 Flutter 框架异常。
