# 位图与 SVG 识别回归

2026-11-19，SaaS 全模板 Android 验收发现公共山峰 PNG 的 C2PA 元数据含有 SVG 片段。原加载器在前 4096 字节中任意匹配 SVG，误用 SVG 解码器；正文资源失败并正确阻止截图。

识别先确认文件起始内容为 XML 文本，再寻找 SVG 根元素。PNG/JPEG 等二进制位图交给 Flutter 原生解码器，保留原缓存字节、URL、图片尺寸及资源就绪流程；不修改正文协议或宿主保存链路。真实 SVG 保留 BOM、前导空白和 XML 声明支持。

`collab_cached_image_format_test.dart` 通过原文件缓存和真实 Widget 验证带 SVG 元数据的有效 PNG/JPEG、普通 SVG、BOM/XML SVG，核对真实绘制就绪、无失败占位及卸载释放。两个位图用例修复前稳定失败，修复后全部通过。夹具仅为 8×8 人工色块，不含业务数据。
