## 2026-10-29 bodyContent 记事本业务适配

按桌面 `cses-client/.npmrc` 的 @ccc registry 实时查询 latest 返回 **0.11.31**；声明及 Yarn 锁定为 **0.11.33**，安装为 **0.11.17**，本轮未升级桌面依赖。已核对安装 .17 与缓存发布 .31 的随包 L0 技能/迁移、行内对象指南、DocConfig.embeds 声明及 EmbedConverter 实现；声明 .33 并非本机实际运行版，不宣称验证了 .33 发行实现的全部行为。

本轮只增加 example 宿主的 BodyContentCodec：对 daily-writing 模板做栏目投影，原核心块注册及通用 Codec 不变。dailyTag 为样例提供的宿主业务标签，help/pilot 在校验前取出并映射原业务行，提交时还原，不将未知行内对象加入通用白名单。任务/会议/文档等引用使用原生实体显示，仅扩展日记端身份校验，不降级为人员。

原模板骨架、块身份和属性保留；新段落继承来源 ID 时按运行时身份区分，避免重复。栏目隐藏状态为 root meta 的可选 mobileGuidanceView 扩展，不改变正文内容。未支持的可编辑块、标签及锁定正文整次拒绝；模板 incl 中列出的媒体类型不代表本轮已开放媒体菜单或完成高级块适配。
