# SaaS 日导向公司模板适配

保留原表单和原预览，新建公司模板内编辑器及只读预览，两者兼容共存。原字段、原保存接口、列表和统计行为保持不变；已有记录的编辑与独立模板预览使用新详情接口读取正文。用户只要求规划或审查时，完成对应文档或发现，不自动实施生产代码。

先读适用的仓库规则及模块说明，再按需读[迁移方案](../../saas-daily-guidance-migration.md)：第 1–3 节是范围、原字段和保存流程，第 4–5 节是模板与最小接点，第 6–8 节是实施、验收及具体验证项。若安装位置不同，从编辑器仓库查找该文档。

## 已确认边界

- 原表单 `create/` 和原 `lib/modules/templates/` 保持不动。新编辑器与模板副本放在 Mutualism 的 `presentation/orient_result/editor/`，仅新建时选择方式，已有记录修改统一进入编辑器；旧详情附加独立模板预览；不在旧模板页面、Shell 或注册表内接入编辑器。

- 后端旧表单保存会按原字段重建正文，因此不能让已有记录退回旧表单覆盖编辑器排版和自定义栏目；保留的是原表单创建入口。
- 后端已刷新并补齐历史 `bodyContent`，不安排前端历史回填、批量迁移或重复确认。四个列表接口不再返回正文；编辑和模板预览按具体槽位的业务 ID 读取新详情根 `body_content`。接口仍允许 null/空对象，必须只读保护，不能据此自动回填或覆盖。
- `ORIENT` 展示“成果导向”，`RESULT` 展示“工作成果”；协议标识、原字段名不变。
- 创建和编辑用同一快照编码 `bodyContent` 并抽离原字段，经原请求构造和 `/dailyOrient/save` 保存。沿用原身份、权限、非计数校验、事件、返回和预览流程。
- 新编辑器解除原表单全部字数和条数限制，包括主内容 30 字、感悟/自检 300 字、业务条目 50 字、每类 3 条以及保存时最少 5 字。输入、粘贴、加载、抽离、保存和重开均不截断或重新套用旧限制；主内容非空、中文及权限规则保留；共存的原表单不改变其限制。
- 任意栏目中的都来帮/领航员均抽离到 `helpItems/navigatorItems`，同时完整保留来源栏目内容及其对应原字段。两条规则已确认，不再要求用户确认或列成待决事项。
- 列表、统计、待办、复制及互动的展示和业务不改造。详情读取属于编辑/预览入口适配，不能继续要求列表透传正文；详情不携带行为统计，保留来源上下文，不能用缺省值清零。

## 宿主复用优先

不要整目录搬运 example。迁入组件前先检索 SaaS 及其 Common/Widgets 依赖：已有弹窗、名称编辑、菜单、头像和分享能力优先直接复用；只有正文会话、栏目事务、模板正文槽和测量等缺失能力才增加适配代码。原模板实现与流程保持不动，允许为组件复用补充模块公开导出；主图和品牌页脚直接使用 TemplateImageView、BottomLogoImageView，不复制其图片渲染与缓存逻辑。截图在宿主等待这些现有组件资源就绪。

`@` 单选、都来帮/领航员多选均使用 SaaS 公司人员选择器，由 Composition 注入；不得复制人员搜索弹窗、目录树或以新造的选人 UI 替代。保留真实人员身份、排除自己、取消留下空业务行和迟到结果守卫。轻提示使用 SaaS 公共 showToast，不使用 ScaffoldMessenger/SnackBar。SaaS 仅显式提交原接口，不迁入 example 本地存储、自动保存、演示服务或原生分享桥。验收时检索并删除未使用的示例组件。

## 原字段适配

以 SaaS 原 `create/logic.dart`、`keys.dart` 和原模型为准，不直接使用 example 的请求序列化结果。

- 主字段仍为 `dailyOrientContent/dailyResultContent`，仅提交当前类型；`bizType` 分别为 `DAILY_ORIENT/DAILY_RESULT`。
- 原内容对象是 `{content, mentions: [{userId, userName}]}`。帮助、领航从全文各栏目分别按文档顺序聚合，保留该对象数组，不加 `sortNo`、不限制条数；每个实际条目在对应数组出现一次，不合并不同的同文条目。
- 空感悟、自检仍按原逻辑省略；`todoContent/expectedEffectContent/customData` 为 `{}`，`contentSnapshot` 为 `''`。只追加 `bodyContent`，不自定 null、新字段名或引用协议。
- 旧表单后端生成的 todo/expected-effect 区域不混入主栏目：只有空白普通段落及模板标题时不生成可编辑占位，有正文、人员提及或复选项时分别作为“要做的事 / 预期效果”独立栏目展示。原区域、块 ID、锁定标题、扩展和隐藏视图状态保持，未改正文编码无损；仍按原约定提交空 todoContent/expectedEffectContent，不把历史字段内容误收为主字段。历史栏目的内部标识（包括 todo/expected-effect 和另一类型 legacy-orient/legacy-result）必须避让真实自定义字段，保持真实字段标识/标题和隐藏状态；嵌套区域继承避让后的归属，不通过保留字限制已有后端数据。
- 对照后端 `BodyContentMapper` 的真实树验证：`daily-body` 是嵌套容器，独立 help/navigator 等子区不混入主字段；识别祖先区域业务标记并跳过锁定标题，原嵌套结构、稳定 ID 和另一类型 legacy 区域无损保留。不能只用扁平手造数据验收。
- 嵌套区前后的正文按稳定锚点和实时顺序回填，覆盖无修改、插入和删除；另一类型 legacy 内部的 daily-body 不能重新归入当前主栏。未改变视图状态时保留显式 null、空对象和空数组；编辑块时不能丢失未开放编辑的未知扩展。
- 旧字段保留原文本规范化；完整格式和换行保存在正文。非用户引用不能冒充用户 ID。
- 主栏目、感悟、自检和自定义栏目中的 help/pilot 都参与聚合；只识别业务标记，跳过空条目，不从来源栏目移除文字或引用。隐藏但保留内容的栏目参与抽离，实际删除的条目不再聚合。
- 自定义栏目完整保存在正文，原 `customData` 不另造格式；其中的 help/pilot 同样进入对应数组。来源字段与数组项分别保留用户 mentions，预览和分享只按正文原位置渲染一次，不再拼接数组副本。
- 原 `OrientResultSubBean` 保持首页、保存及列表响应协议，不把新详情交给它直接解析。`OrientResultDetailDto` 独立映射根 snake_case 的 26 个业务字段并完整保留 JSON，宿主再适配编辑会话；不要从旧 Bean 的简略 `toJson` 重建写入请求。

## 详情读取与入口保护

读取先核对目标 SaaS `lib/modules/mutualism/DETAIL_API_UPGRADE.md` 第一部分：`POST /dailyOrient/detail` 仅传裁剪后的真实记录 `id`，使用已有会话头；成功须 HTTP 200 且根 `isSuccess:true`。不从正文 ID、列表父容器或 rootId 猜测，不走 `/page/data/detail` 或 `/page/load` 降级。

- 已有记录编辑、重开及独立模板预览均先加载详情；入口按记录 ID 可用，不按列表正文缺省判断未填写。新建无 ID 才构造内存空文档，原表单选择继续共存。
- 详情成功、身份匹配且正文受支持后才创建编辑会话；加载和失败时不挂可写文档。失败允许重试，重试及切换记录使用宿主已有异步守卫；退出或切换公司/账号后永久丢弃旧结果，不覆盖未保存输入。
- 根 `body_content` 与所有 JSON 列保留未知属性、显式 null、空容器和顺序，不套用旧列表内容清理规则。null 提示“暂无完整正文”；空对象或不支持文档只读展示本次详情原字段，禁止生成默认正文保存。
- 详情读取权限不代表编辑权限；仍核对作者、业务日和原填写窗口。保存保持原接口；按详情协议在确认保存后重读同一记录、刷新来源列表，读取失败不能触发重复提交。
- 保存成功立即冻结编辑，详情校验完成后才允许预览与分享；失败显示已保存且仅重试读取，退出仍返回保存成功。已有记录没有修改时可直接读回，不额外提交。页面负责所有旧/新 Controller 的退场释放，不把原提交快照当作详情读取成功。

## 公司模板与编辑预览

- 从实际注册表 builder 和变体策略建立公司、部门、固定版/V2、共享品牌及兜底覆盖矩阵，沿用原选择规则。三套 example 仅作交互参考，新代码按 SaaS 原版还原素材、裁剪、取景、日期和装饰；只复用原素材与公开组件，原目录只读。以下高度约束适用于全部迁入 SaaS 的公司模板；离线 example 可保持自己的画布规则，不将其填屏实现迁入 SaaS。
- 当前新入口按固定公司 ID 分发：汇丰永盛 → HFYS V2，成塔服饰 → CTFS V2，其余公司暂保持中企云链试点兼容。这两家公司没有部门分支，按用户确认固定 V2，不因可选栏目为空降级固定版；原注册表规则不变。入口文案、创建、详情编辑和只读预览共用解析规则，路由捕获公司身份后固定模板，保存读回与分享继续使用同一模板；未知公司采用兼容版不等于该公司原模板已迁移。
- 在独立模板正文槽接一个活动编辑会话。Mutualism 新宿主拥有画布、截图、业务和保存，根包仅提供通用能力；原 Templates 及其调用方不变。
- 编辑测量当前草稿，预览和长图按同一已保存正文、宽度和样式测量自然高度，不沿用旧摘要高度。重测不卸载活动输入树，镜像和测量只读。
- 编辑态上方主图固定为原模板在当前宽度下的最小高度，不因短文、屏高或键盘弹出而增高。编辑画布从页面顶部开始，整体滚到透明状态栏，不新增顶部占位；预览保留原模板自身的顶部安全区。保持原内部文字位置，返回、保存、撤销、重做悬浮于顶部；栏目操作使用键盘菜单。
- 预览和长图的完整画布为“上方模板 + 编辑器正文自然高度 + 满宽 Logo”，最低为手机完整屏高。先按主图最小高度测量；短文不足一屏的差额全部增加到主图高度，长文主图保持最小高度、画布随正文自然增长。正文不得增加空行、横线或固定空白填屏；正文结构、用户换行、空段和样式完整保留在 `bodyContent`，显示沿用现有只读渲染及栏末纯空段折叠规则，布局不新增、删除或改写正文 JSON。保留原图裁剪、日期和装饰，预览与截图使用同一高度与取景；计算细节见迁移方案第 4.3 节。
- 公司 Logo 在编辑时隐藏，保存预览与分享时按比例铺满画布宽度。正文、图片和页脚完整进入长图，操作层不进入截图。
- 感悟、自检、都来帮、领航员、自定义栏目按需添加；验证关闭、恢复、撤销和保存重开。除已确认的主图补高、顶部和 Logo 模式差异外，正文外素材、裁剪、日期、装饰及层叠按原版还原。
- 按真实正文核对 Codec 和只读渲染支持范围，不把根包所有插件自动开放。格式损坏/不支持时不静默清空。固定模板的长文容纳按实际测量验证，确需选已有 V2 时记录最小调整。
- 只读预览使用原版固定底部“分享 / 随机图片 / 图库 / 取消”，上方模板滚动且无顶部返回；固定栏复用公共 Blur 半透明磨砂与柔和阴影，画布外的防遮挡尾距保证 Logo 可完整滚出。固定栏及底部安全防遮挡尾距不计入画布高度、不用于补足一屏，也不进入截图；预览及分享路由从底部滑入，编辑态顶部操作保留。随机图、来源菜单、本地相册/裁剪和云图库均复用现有能力，只改变当前预览来源。图片拖动取景直接复用 TemplateImagePositionController / Scope、TemplateImageLoadTracker 与 TemplateImageView，成功换图居中、取消保留，截图锁定并使用同一取景和真实首帧；禁止复制手势与加载逻辑。点击分享才截图并进入原版黑色图片区及白色平台操作栏。保留原分享渠道、回写和日期行为，不重建分享系统。

## 实施与验收

首批用独立中企云链模板跑通两类记录，并验收旧表单共存；HFYS V2、CTFS V2 已接入新公司分发，验收状态以对应记录为准；后续最终按原注册表覆盖全部可达模板。example 的公司入口未绑定两类选择，不能替代生产两类验收。

重点验证：除 `bodyContent` 外请求结构和原规范化不变，字段值遵循来源保留与全文聚合规则；超过原字数/条数上限和少于原最少字数的有效正文可保存重开；跨栏目聚合的顺序、用户 mentions、不重复收集及原文保留；同快照保存、中文键盘、长图、动态栏目、全宽 Logo 和原版视觉。短文仅主图补高、长文自然延伸、编辑主图不随键盘变化，预览和截图画布一致且没有为填屏新增的正文块、横线或空白；原列表、统计等继续使用原字段。选填清空语义和固定模板长文容纳依方案第 8 节验证，不把已解除的限制或已确认的聚合规则重新列为开放问题。

按仓库规范核对依赖、格式化、分析、目标测试、消费者和真机，归档证据并执行 `git diff --check`。不把静态核对、Mock 或 example 记录写成 SaaS 已验收；涉及块协议变更时再执行对应核对流程。
